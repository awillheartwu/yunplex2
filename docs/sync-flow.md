# 同步与媒体复用流程

当前实现只有两个运行时身份事实：

- `local_media_assets`：本地文件路径、来源、managed/external 归属与连续性。
- `song_identity_bindings`：`path` 托管路径关联或 `manual` 明确接管。

候选审核、身份事件、provider GUID 与 MusicBrainz 匹配已经退出运行时。

## 自动解析

每个网易云目标按以下固定顺序处理：

1. 验证已有 `manual` 接管：ratingKey 存在且 Plex 路径完全一致；ratingKey 改变时只允许用同一精确路径恢复。
2. 检查 YunPlex 托管文件：只有唯一 Plex `Media.Part.file` 与映射后的本地路径完全一致才复用并写入 `path` 关联。
3. 同一路径对应多个 Plex 媒体时标记身份冲突，本轮不修改该目标。
4. 其余情况直接下载独立托管副本；外部文件路径受到保护，不会被覆盖。
5. 下载完成后触发 Plex 扫描，并仍然只按精确路径等待索引。

Plex 标题、艺人、专辑、时长、GUID 与刮削器信息不参与上述判断。因此 Plex 使用 MusicBrainz 或其他刮削器只会改变展示，不会改变 YunPlex 的媒体关联。

默认路径会包含 `[netease-{songId}]`。自定义格式未写 `{songId}` 时，系统也会自动追加，避免同名歌曲覆盖。

## 明确接管外部媒体

同步源的“媒体与歌曲”允许按标题搜索 Plex，但搜索结果只是选择器，不是自动候选：

1. 用户选择具体 Plex 媒体。
2. 系统保存 `manual` 关联及精确路径。
3. 受影响来源标记为待对齐。
4. 后续同步自动验证该 ratingKey 与路径；失效时取消自动复用并下载托管副本。

取消接管后，下次同步重新按托管规则处理。

## 预览与自动下载

`preview` 使用同一规划器，但不写业务状态、不创建下载任务、不扫描或修改 Plex。无法验证媒体时，正式同步自动下载，不再提供“继续猜测”开关。

## Plex 删除保护

来源定义目标成员和顺序，但删除额外项必须同时满足：

- 本轮网易云目标完整，没有歌曲详情缺失或身份冲突。
- 额外项达到配置要求的连续观察次数。
- 身份版本在计划和提交之间没有变化。
- Plex 写入后读回结果与目标一致。

删除只针对具体 Plex `playlistItemID`，不会删除音乐库文件。任一条件不满足时保留该 occurrence 并记录原因。
