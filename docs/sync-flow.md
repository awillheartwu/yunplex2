# 同步与媒体复用流程

当前实现只有两个运行时身份事实：

- `local_media_assets`：本地文件路径、来源、managed/external 归属与连续性。
- `song_identity_bindings`：`path` 托管路径关联或 `manual` 明确接管。

旧日常候选审核、身份事件、provider GUID 与 MusicBrainz 自动匹配已退役。首次媒体接管保留独立的候选审核；它只辅助用户作决定，不作为日常自动身份事实。

## 自动解析

每个网易云目标按以下固定顺序处理：

1. 验证已有 `manual` 接管：ratingKey 存在且 Plex 路径完全一致；ratingKey 改变时只允许用同一精确路径恢复。
2. 检查 YunPlex 托管文件：只有唯一 Plex `Media.Part.file` 与映射后的本地路径完全一致才复用并写入 `path` 关联。
3. 同一路径对应多个 Plex 媒体时标记身份冲突，本轮不修改该目标。
4. 其余情况按未验证媒体策略处理：`download_managed` 下载独立托管副本，`wait_manual` 等待用户选择。外部文件路径受到保护，不会被覆盖。
5. 下载完成后触发 Plex 扫描，并仍然只按精确路径等待索引。

Plex 标题、艺人、专辑、时长、GUID 与刮削器信息不参与上述判断。因此 Plex 使用 MusicBrainz 或其他刮削器只会改变展示，不会改变 YunPlex 的媒体关联。

默认路径会包含 `[netease-{songId}]`。自定义格式未写 `{songId}` 时，系统也会自动追加，避免同名歌曲覆盖。

## 明确接管外部媒体

同步源的“媒体与歌曲”允许按标题搜索 Plex，但搜索结果只是选择器，不是自动候选：

1. 用户选择具体 Plex 媒体。
2. 系统保存 `manual` 关联及精确路径。
3. 受影响来源标记为待对齐。
4. 后续同步自动验证该 ratingKey 与路径；失效时取消自动复用，并回到上述未验证媒体策略。

取消接管后，下次同步重新按托管规则处理。

## 预览与自动下载

`preview` 使用同一规划器，但不写业务状态、不创建下载任务、不扫描或修改 Plex。无法验证媒体时，正式同步根据策略下载或等待手动选择，不提供“继续猜测”开关。

## Plex 删除保护

来源定义目标成员和顺序，但删除额外项必须同时满足：

- 本轮网易云目标完整，没有歌曲详情缺失或身份冲突。
- 额外项达到配置要求的连续观察次数。
- 身份版本在计划和提交之间没有变化。
- Plex 写入后读回结果与目标一致。

删除只针对具体 Plex `playlistItemID`，不会删除音乐库文件。任一条件不满足时保留该 occurrence 并记录原因。

## 来源请求与接管生命周期

普通单源、批量、全局、来源失败重试通过 `source-requests.ts` 接受请求。普通手动同步忙时拒绝，不产生新任务；空闲的混合批次一次事务接受，就绪来源先同步，需要接管的来源随后分析，等待确认的来源保持等待。调度入口调用同一分流逻辑。`worker.ts` 是分析与 Source Convergence 的唯一持久消费者，审核不占执行槽位，Repair 与来源执行互斥。

重新分析携带当前初始化 ID，在事务内取消旧草案及 Run、创建新分析请求。旧页面得到明确冲突并需刷新；重复启动分析复用请求，应用中的草案不可重启。分析失败、排队或服务停止不会打开普通同步闸门；只有已完成或用户明确跳过接管才可放行。

最终提交同时保存身份、稀疏决定、初始化结果、Run 结果和后续同步请求。外部验证之后在最终事务中重新读取来源启用状态，禁用来源不续接；数据库错误全量回滚，单曲身份冲突转为待处理。重复提交返回已保存结果和同一后续请求 ID。worker 唤醒在提交之后，未唤醒的请求仍能在轮询或重启后恢复；启动同步后补充双向 Run 关联。

候选快照有固定规则版本。已有验证绑定是只读项目；可决策项目由服务端提供允许操作及原因，客户端与服务端共享类型。规则不兼容的旧草案可查看但不可编辑或提交，需要重新分析；既有正式绑定不受影响。

## 文件任务与后续对齐

同步、Repair、手动下载把各自计划交给 `file-task-command.ts`。提交返回实际任务 ID 与复用结果，唤醒全局消费者和等待本批任务分开；去重不转移原任务归属，各调用者保存自己的结果关联。Repair 只等待本批文件任务，随后可刷新 Plex 媒体库；Plex 歌单变更仍仅由 Source Convergence 执行。

取消一次来源请求或批次只停止相应等待和后续 Plex 操作，共享文件任务继续服务其他调用者。单曲重试成功只提交资产并标记关联来源待对齐，不自动同步；页面显示“下载完成，待同步”，来源完成对齐后该动态提示消失。来源页面按请求 ID 和来源 ID 更新状态，不把已接受显示为正在同步，也不因无关任务的 idle 事件清空当前状态。

本地验证使用临时 SQLite、可控文件、外部服务替身和隔离浏览器服务。真实网易云/Plex、NAS 重启与长期运行验收单独记录，不以本地检查替代。
