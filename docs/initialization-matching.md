# 初始化匹配与快速接管

歌单第一次同步前要先做一次“首次媒体接管”。系统只读网易云歌单和 Plex 音乐库，生成接管方案；你确认之前不会下载，也不会改 Plex。

来源也可以跳过接管。跳过会按普通同步的未接管策略处理，可能马上排很多下载。

## 三步操作

1. 开始分析：在来源的“首次媒体接管”里点“开始分析”。系统保存分析方案，不改音乐文件或 Plex。
2. 定分数线并预览：打开“快速方案”，选分数线（0–100，默认 85），点“生成快速预览”。已经关联好的歌保持不变；其余按当前分数线采用合格候选，没达到的进入下载计划。预览会列出保留、复用、共享和下载各多少首。
3. 确认并启动处理：点“确认并启动处理”整批应用预览结果，普通同步随后处理下载与入库。也可以“仅保存草案”暂不执行；之后在快速方案里点“提交并启动处理”，或关闭面板后点页面底部的“提交接管方案”，都会提交当前草案。未再次编辑时可以恢复保存前的决定。来源即使已禁用，也能这样处理一次，不会改变启用状态。

提交后接管状态变为“已完成”；下载、写入标签与 Plex 入库在普通同步中执行，进度和结果可在来源的“运行记录”里查看。

## 评分与风险

评分满分 100，只比较元数据：标题 35 分、艺人集合 35 分、时长 20 分、专辑 7 分、曲序 3 分。有争议的版本差异每处扣 10 分，最多扣 30 分；缺失项不加分。文件名、音质和目录偏好不加分。

演唱者冲突、歌曲 ID 矛盾、版本冲突、路径缺失或不唯一的候选不参与快速采用，只会进入人工处理。

分数表示匹配程度，不是正确率，85 分也不保证匹配成功。分数线越低，误匹配风险越大，需要人工抽查；第一名和第二名接近时只提示风险。

## 设置分组

- “匹配总开关与预设”：增强匹配默认关闭；预设只填可见参数，之后改动即为自定义，切换预设不影响已设的别名和首选目录。
- “标题与艺人规则”：简繁、全半角、双语、模糊标题、扩展召回等如何比较标题和艺人；路径只做提示，不能单独建立关联。
- “批量推荐策略”：多个候选时默认选质量最高的合格候选，也可改为全部复核；忽略缺失合作歌手、拉丁重音、双语交叉、MusicBrainz 等增强项默认关闭，开启也不放宽版本和身份保护。
- “快速初始化”：只保存快速方案的默认分数线，不影响已有方案。
- “时长与版本规则”：区分直接推荐和人工确认；现场、伴奏、翻唱、混音等版本差异不会被时长或艺人证据掩盖。

## 艺人名与 MusicBrainz

“艺人名称”里的别名组让不同写法被当成同一艺人；“原名称 → 写入名称”是单独的写入替换，不会重命名已有文件。别名建议来自本次分析，需要你确认保存才生效。

MusicBrainz 是可选的外部补充，用来找艺人异名，默认关闭且要配合艺人别名使用。只发送待审艺人名，只采纳名称精确、没有同名歧义的记录，也不会自动修改手工别名。

## 重新分析、共享确认与纠错

数据或规则有变化时，页面会提示重新分析；提示出现后原结果只能查看，重新分析才能继续。重新分析会重新读取数据、生成新方案，已确认的媒体关联会保留，草案中未提交的选择需要重新确认。

多首歌推荐到同一个 Plex 媒体时会标“共享媒体待确认”；核对整组信息并确认后才会共用。共享只是复用同一个文件，不合并歌曲 ID 和歌单位置，撤销其中一首不影响其他。

“歌曲与媒体”里可以做两种纠错：

- 更换匹配：改选其他 Plex 媒体，校验当前关联后保存；启用的收藏会自动对齐。
- 改为下载：另下一份托管副本，经 Plex 验证后才切换；失败保留原文件和原关联。
