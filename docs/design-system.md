# reYunPlex 界面设计系统

这份文档是管理界面的视觉与交互基线。页面可以根据业务调整信息结构，但不能创建独立配色、圆角、阴影或响应式规则。

## 设计方向

- 媒体内容参考 Navidrome：封面承担内容色彩，控制台本身保持中性。
- 筛选和批量操作参考 Music Assistant：桌面使用触发器附近的 Popover，移动端使用底部 Sheet，已启用条件显示为 Chip。
- 任务和下载参考 SABnzbd：紧凑、可扫描，摘要优先，详情按需展开。
- 系统状态参考 Immich：少量状态卡和明确异常，不把监控做成独立复杂控制台。
- 列表筛选参考 Paperless-ngx：搜索、筛选、批量选择遵循同一顺序。

## 视觉规则

- 唯一强调色为靛蓝；绿色、橙色、红色仅表达语义状态。
- 亮色使用冷灰背景和白色表面；暗色使用深蓝黑背景和低亮度蓝灰表面。两套主题结构完全一致。
- 页面最大宽度、控件高度、卡片圆角、阴影和间距均来自 `assets/css/main.css` 的令牌。
- 卡片只使用边框和一级轻阴影，不叠加玻璃、发光或页面专属渐变。
- 正文和标题使用 Inter/PingFang SC；路径、ID 和日志使用 JetBrains Mono。

## 组件规则

- 页面标题由顶栏承担，`PageHeader` 只放一句用途说明和页面级主操作。
- 页面一级导航统一使用 `PageTabs`。
- 搜索和筛选统一使用 `FilterBar`；宽屏筛选是 Popover，窄屏筛选是底部 Sheet。
- 普通操作使用次要按钮，页面唯一主操作使用主按钮，危险操作必须使用危险语义。
- 列表行默认紧凑，点击进入详情或展开；低频操作进入更多菜单。
- 选择项目后才显示批量操作，不长期占用页面空间。

## 响应式与无障碍

- 验收断点：375、768、1024、1440 像素。
- 触控目标不小于 44 像素；紧凑桌面按钮在移动端必须恢复触控高度。
- 图标按钮必须提供 `aria-label`，筛选、Tab 和 Switch 必须暴露当前状态。
- 不能只依赖颜色表达成功、警告和失败。
- 所有动画遵循 `prefers-reduced-motion`。
