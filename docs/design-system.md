# reYunPlex 音乐工作台设计系统

当前界面以音乐收藏和待处理工作为中心。参考 [Music Assistant 的音乐导航](https://www.music-assistant.io/ui/)以及 [Linear Inbox](https://linear.app/docs/inbox) / [Views](https://linear.app/docs/custom-views)，保留业务服务与身份安全边界，重建前端组织方式。

## 页面职责

| 板块 | 路径 | 核心工作 |
| --- | --- | --- |
| 工作台 | `/` | 最近收藏、待处理收件箱、全局同步控制与收藏状态；不加载资源监控 |
| 音乐库 | `/sync-sources` | 封面网格 / 紧凑列表，歌单与专辑筛选、搜索、选择和批量操作 |
| 添加音乐 | `/manual-download` | 输入链接、解析歌曲、选择并提交下载；选项按需展开 |
| 活动 | `/task-center` | 进行中、历史运行与待处理事项；展示实际当前 Run 和文件任务 |
| 偏好设置 | `/config` | 服务连接、文件、同步策略、外观、安全维护；分类支持直达 |
| 系统状态 | `/system` | 服务与资源、运行日志两种视图；监控图表集中于此 |

`/logs` 保留为日志直达路径。来源详情、运行详情和高级媒体关联保持可直达。主导航与页面上下文由 `lib/navigation.ts` 统一管理。

## 应用框架

- 桌面：固定侧栏，日常工作与管理入口分组；顶栏提供面包屑、全局搜索、主题和账号操作。
- 手机：工作台、音乐库、添加音乐、活动使用底部导航；更多管理入口在抽屉中。
- 全局搜索可通过按钮或 Cmd/Ctrl+K 打开，搜索实际音乐来源与页面，方向键选择、Enter 打开、Esc 关闭。
- 搜索、确认和添加收藏弹层管理焦点与背景滚动；Esc 关闭、Tab 留在当前弹层，提交过程中禁止重复操作。短屏确认窗口仅内容区滚动，操作按钮留在窗口内。
- 证据抽屉、筛选、日期选择和手机导航也共用 `useDialogFocus`。嵌套弹层只处理最上层的键盘事件；关闭后恢复父层焦点和滚动锁，最后一层关闭后恢复页面。证据详情通过 Teleport 展示，披露区的 `summary` 保留键盘访问。
- 底部导航、设置保存条与正文分别留出安全空间。

## 内容与操作

- 音乐库使用同一 `LibraryCollection` DOM 切换网格/列表；视图持久化，切换不丢选择。自定义顺序下才允许拖动；搜索或其他排序下禁用。
- “网易云收藏歌单”按 `subscribed` 筛选；“已绑定 / 未绑定 Plex 目标”按已记录的非空目标 ID 筛选，二者可以组合。Plex 筛选不证明目标当前在线、同步完成或媒体身份已验证。筛选浮层的内容区滚动，操作区保留在视口内。
- 来源封面使用真实 URL；缺失或失效时显示类型图标，不编造封面、音乐数或任务结果。
- 批量操作只在有选择时出现；同步必须满足来源启用与互斥条件，危险维护保留确认。
- 来源详情强调封面、名称与主操作；低频维护收进披露区。歌曲与接管仍使用原有验证及提交契约。
- 添加音乐未解析时不渲染大块空结果。解析成功后收起原始输入，歌曲选择与下载提交成为焦点；失败和结果反馈位于披露区外。
- 下载选项默认收起，并在摘要中显示音质、歌词与标签策略；解析历史保留快捷回填。
- 活动按工作状态组织；空闲时给出前往音乐库和添加音乐的入口，真实活跃 Run 不能被空闲提示覆盖。
- 偏好支持分类检索和 `?tab=` 直达。底部保存条统一展示未保存状态、放弃和保存；放弃只恢复表单，不写入服务器。
- 全局与来源设置通过 `UnsavedChangesGuard` 保护离开与刷新；退出登录先确认编辑去留，再结束会话。同一来源切换页签保留草稿，切换来源 ID 仍需确认；草稿只留在当前页面内存，不将配置凭据写入本地存储。
- 保存失败保留表单；保存期间继续输入的内容不会被旧响应覆盖。保存中的离开请求等待结果，成功且没有后续修改时继续离开，失败时仍允许继续编辑或明确放弃。
- 读取失败与空数据明确分开；配置读取失败禁用保存，音乐库和日志提供重试。
- 来源详情与运行记录独立读取；运行记录失败不隐藏来源。后台更新不重建同一来源的设置编辑器。
- 来源数值覆盖清空后按 `null` 保存为继承全局；全局默认值读取失败时显示未知，不以猜测值冒充当前策略。
- 添加收藏始终可切换到资源 ID 输入，输入须为有效正整数；错误说明完整显示。

## 视觉语言

- 中性暖纸色 / 深橄榄炭色背景，铜橙强调色；以封面与内容组织页面，减少重复卡片包裹。
- 强调色只用于主操作、当前导航、选择与重点内容；成功、运行、警告、失败继续有独立语义色。
- 颜色与设计尺度从 `assets/css/tokens.css` 取值，CSS 与 Tailwind 共用同一组变量。深色按钮、选中徽章和复选框使用 `--on-accent`。
- 列表紧凑，媒体网格宽松；标题、元信息与操作区域保持明确层级。页面标题不重复显示多层分组标签。
- `SourceSummaryContent` 拥有内部样式，详情不依赖音乐库页面曾经加载。

## 样式所有权

| 文件 | 职责 |
| --- | --- |
| `assets/css/tokens.css` | 明暗主题、语义色、字体、间距、圆角、阴影、动画时长、控件尺寸和层级的唯一取值来源 |
| `assets/css/main.css` | 基础排版、页面尺寸、焦点、减少动画偏好及语义工具类 |
| `assets/css/global/controls.css` | 按钮、输入框、复选框、图标按钮及其交互状态 |
| `assets/css/global/components.css` | 共享卡片、筛选、日期弹层、提示及手机适配 |
| `assets/css/pages/*.css` | 对应页面的结构与响应式布局；不重新定义主题或字体尺度 |
| `assets/css/components/*.css` | 由所属 Vue 组件显式、带作用域地导入；接管审核、证据抽屉和提交栏分别拥有内部样式 |
| Vue 组件的 `style scoped` | 组件内部布局；跨子组件的页面样式明确使用 `:deep` 或页面专属全局选择器 |

Nuxt 先载入 `assets/css/fonts.css` 的本地字体声明，再按上表前四项的顺序载入基础样式，Tailwind 入口明确指向 `main.css`，避免模块额外注入默认基础样式。页面样式按页面加载；添加音乐分为流程框架、链接输入与下载选项、歌曲结果，活动分为页面框架、运行概览、异常列表。不要用另一个页面的加载顺序隐式提供子组件样式。

同一模块的基础规则、状态规则和响应式规则集中维护；相同条件下同一选择器只定义一次。已整理的配置、活动、添加音乐及接管样式由结构检查防止重复规则和压缩长行回流。接管共享徽章样式由每个使用它的组件显式导入，父面板不再通过全局选择器控制审核表格或 Teleport 抽屉。

明暗主题共享页面结构与语义背景。添加音乐已移除旧的暗色专用变量和强制背景覆盖；主题差异由基础颜色变量表达。

## 字体与尺度

字号均使用 `rem`，以 16px 根字号为基准。外观设置通过 `--font-scale` 同步缩放文字与控件。

| 变量 | 标准大小 | 用途 |
| --- | --- | --- |
| `--text-xs` | 12px | 时间、状态、辅助说明；常规界面最小字号 |
| `--text-sm` | 13px | 紧凑列表、表单标签 |
| `--text-base` | 14px | 正文、输入框、按钮 |
| `--text-md` / `--text-lg` | 16 / 18px | 内容分组与小节标题 |
| `--text-xl` / `--text-2xl` | 20 / 24px | 面板标题、手机页面标题 |
| `--text-3xl` / `--text-4xl` | 32 / 36px | 数字重点、桌面页面标题 |

- 字体统一为 `--font-ui` 和 `--font-mono`，包含中文与系统回退；标题沿用同一字体。字重只使用 400 / 500 / 600 / 700。
- Tailwind 的 `text-base` 对应正文 14px；`text-2xs` 保留为 12px 兼容入口。页面 CSS 使用同名设计变量。
- `--space-*` 以 4px 为单位，允许 2px 半步处理紧凑内部间距。版块优先 16 / 24 / 32px，面板内边距优先 20px。
- 圆角从 `--radius-xs` 到 `--radius-2xl` 为 4 / 6 / 8 / 12 / 16 / 20px，胶囊使用 `--radius-full`；圆形几何可使用 `50%`。
- 普通控件最小高度 40px，紧凑控件 36px，小型辅助控件 32px；手机共享按钮和表单控件最小高度 44px。
- 动画使用 150 / 200 / 300ms 三档，遵守 `prefers-reduced-motion`。键盘焦点使用实线轮廓及主题光环。

## 色彩与层级

- 中性色按应用背景、侧栏、卡片、浮层、输入区分工；内容按主文字、次文字、辅助文字分层。
- 状态统一使用 `success`、`existing`、`ignored`、`warning`、`danger`、`running`。同步、下载、修复类型分别使用 `run-sync`、`run-download`、`run-repair`；这些颜色不承担正式身份判断。
- 状态浅背景和边框由状态色混合生成，随主题切换；不要在组件内写十六进制、RGB 或 HSL 颜色。
- 选中色上的文字用 `--on-accent`，固定浅色装饰用 `--on-solid`，不直接写白色。已测试的明暗主题文字/背景组合以 4.5:1 为对比度下限。
- 层级依次为局部下拉、固定页面区域、手机导航、抽屉、筛选、确认弹层、嵌套日期选择、提示。`lib/overlay-layers.ts` 仅映射 CSS 变量，不另存一套数字。
- 手机正文、保存条、接管提交条和提示共用 `--mobile-dock-space` / `--floating-bottom`，包含底部安全区。

新增样式先复用共享控件和变量。图表几何、布局宽度、根字号缩放以及字体预览可保留必要的计算尺寸；不要为一页新增近似字号或用 `!important` 叠加修补同一选择器。

## 验证与交付

- 自动化验证导航、真实控件、请求归属、筛选与排序、跨模式选择、弹层键盘行为、读取失败、设置回退和底部导航空间。
- 默认不批量截图。需要时以 `UI_SCREENSHOTS=1` 启用；产物不提交。
- 字体随应用本地分发，浏览器检查直接加载本地字体；外网阻断不影响登录首屏。截图仍只按需启用。
- 用户负责最终视觉验收。功能测试及构建通过不代表用户已接受页面美感，也不代表网易云 / Plex 真实服务验收。
- 浏览器测试使用禁用自动同步、未配置生产连接的临时数据库。开发预览使用 3011；先构建后执行 `PLAYWRIGHT_PRODUCTION=1 pnpm test:browser`，会以生产包和独立临时数据库在 3013 验收。确认端口对应隔离预览后，才可用 `PLAYWRIGHT_REUSE_SERVER=1` 复用。禁止本地存储的首屏用例在生产包运行，避免开发专用 Vue Devtools 的直接存储访问先于应用报错。
- `pnpm check:styles` 已接入 `check:ci`，使用 Vue SFC、TypeScript、PostCSS 和 CSS 值解析器检查组件、页面、布局、客户端模块与 CSS。检查命名/数值颜色、静态与绑定样式、工具类、字体/圆角尺度、样式导入、未定义变量及主题内循环引用；回退值也接受检查。
- 变量按全局基础样式、组件局部样式和显式导入关系区分，不能借用其他组件的私有变量。注释、普通文案与 BEM 修饰类不会被当作样式声明。根字号缩放和外观预览保留有明确用途的例外。
- 规则测试包含必须失败的反例，也包含合法主题覆盖、资源 URL 和局部变量的通过用例。静态检查不替代运行时验收；字体缩放、明暗主题、首次打开审核页和抽屉的实际计算样式由浏览器回归验证，不依赖截图匹配。

## 首屏与外观恢复

- Inter 与 JetBrains Mono 从 `public/fonts/` 加载，使用 `font-display: swap`；版本和许可见该目录 README。中文沿用系统字体回退。
- `lib/appearance.ts` 同时提供首屏 head 初始化和运行时更新；仅缓存主题与字号，不缓存认证、Cookie 或完整配置。
- 登录表单先渲染，认证状态最多等待 4 秒；认证完成后异步读取受保护的 `/api/appearance`，最多等待 2.5 秒。外观读取失败保留缓存；较早的响应不能覆盖刚保存的字号。
- 普通 API GET 读取设置 15 秒期限，覆盖响应体读取。写操作不自动重试。

## 大列表与实时恢复

- 音乐库每页 60 个收藏，添加音乐每页 100 首歌曲；分页只限制渲染，选择与提交仍覆盖完整筛选结果或解析结果。来源歌曲与接管审核沿用各自服务端分页。
- `PageNavigator` 统一页码、范围与前后页操作。收藏换筛选或排序时回到首页，拖拽按完整集合的索引提交。
- SSE 单例复用连接中与原生重连中的连接；最后一个订阅取消后释放连接、恢复监听与重试计时器。取消订阅可重复调用。
- 浏览器报告离线时主动关闭旧连接，避免仍显示已连接；连接恢复、重新联网和返回前台时发出客户端 `resync` 通知；音乐库、同步状态、活动、下载队列、运行详情和日志重新读取快照。
- 受理回执提供下一步入口；请求深链接可恢复排队、执行和失败进度。“请求已结束”仍需核对运行记录，不能等同于 Plex 同步成功。
