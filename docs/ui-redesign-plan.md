# 音乐工作台改版计划

本轮重新定义页面结构和操作方式。视觉验收由用户负责；自动化验证聚焦导航、数据、交互与错误状态，截图仅按需开启。

## 参考与取舍

- [Music Assistant](https://www.music-assistant.io/ui/)：音乐内容浏览、全局搜索、手机底部导航。
- [Linear Inbox](https://linear.app/docs/inbox) 与 [Views](https://linear.app/docs/custom-views)：工作分类、待处理收件箱和紧凑列表。
- 不引入播放器或虚构媒体数据；封面与列表使用已配置来源，运行数据使用现有 API。
- 前端结构可以重建，身份判断、文件替换、Plex 删除授权等业务安全边界保持有效。

## 实施与验收

- [x] 应用框架：简明侧栏、手机底部导航、可搜索页面和音乐来源的命令面板。
- [x] 首页：以近期收藏、待办和当前同步为主；系统检测和监控移到独立系统页。
- [x] 音乐库：封面网格与列表双视图，保留搜索、类型筛选、批量启停/同步、来源排序和详情操作。
- [x] 添加音乐：输入区、解析结果与选项分层；未解析时不渲染大块空结果，保留资源身份与失败反馈。
- [x] 活动：进行中、运行记录、待处理三个工作视图；队列与操作按当前工作展示。
- [x] 来源详情与偏好：内容页式封面、上下文操作、维护操作收起；设置可直达分类、能识别未保存修改。
- [x] 更新旧界面断言，验证真实交互，默认不保存全页截图。
- [x] lint、typecheck、相关自动化测试、源码大小和生产构建通过。

## 验证边界

使用关闭自动同步、无生产连接的临时数据库进行功能验证。真实网易云 / Plex 服务验收与用户视觉验收另行进行。测试通过不宣称视觉验收完成。
