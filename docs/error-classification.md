# 统一错误分类

`shared/domain-errors.ts` 是错误码、类别、严重度、重试策略和用户文案的唯一目录。新增失败类型时先扩展目录和分类测试，不应在页面或队列里增加新的字符串正则分支。

## 数据流

- 底层错误保留为诊断信息，但 Cookie、token 和 Authorization 会在进入日志或 API 前脱敏。
- API 失败保持旧的 `{ code, msg, data }` 字段，并增加 `error.code/category/severity/retryable`。
- 新 failure record 使用稳定错误码；旧记录在读取时映射为同一结构，无需数据库迁移。
- 任务中心的标签、颜色、说明和是否可重试均读取同一策略。
- warn/error 日志在读取时投影同一错误码；历史日志也能获得分类。

## 当前稳定错误码

首批覆盖版权限制、网易云认证和限流、Plex 不可用、文件系统错误、媒体身份冲突、调度中断、并发占用，以及已有的下载、标签、Plex 匹配和歌单写入失败。

`unknown_error` 必须用于没有可靠判据的错误。它默认不可自动重试，避免把未知副作用重复执行。底层诊断应留在日志中用于继续补充分类规则。
