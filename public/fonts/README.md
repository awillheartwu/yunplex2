# Bundled fonts

These unmodified WOFF2 files are served locally; no font CDN is needed at runtime.

- Inter Variable, version 4.1: https://github.com/rsms/inter/tree/v4.1/docs/font-files — see `Inter-OFL.txt`.
- JetBrains Mono Regular / Medium, version 2.304: https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts — see `JetBrainsMono-OFL.txt`.

Both upstream license texts are distributed with the fonts. Chinese text uses the existing system font fallback.
